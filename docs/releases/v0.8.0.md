Save more finds, explore whole albums, and queue music links with a clearer, more readable interface.

- Save any recommendation to Wishlist, including unverified AI suggestions without a preview or track count. Later catalog results still update saved records.
- Browse album track lists from Apple Music and Deezer. Switch between available track previews, including tracks beyond the original recommendation. Tracks without clips remain visible, and incomplete catalog lists are labeled.
- Choose a music provider, then open, copy, or queue its URL. Search links cover Amazon Music, Apple Music, Spotify, Deezer, TIDAL, Bandcamp, SoundCloud, YouTube, YouTube Music, Beatport, Traxsource, and Discogs. Matching sharing pages can also supply direct links for Qobuz, Pandora, Napster, Audiomack, Anghami, Boomplay, Yandex Music, QQ Music, NetEase, iTunes, and Amazon Store. Search results and direct release links are distinguished; alternate editions are not silently substituted. Any pasted HTTP/HTTPS provider URL can be passed directly to an external program, including providers outside this list.
- External programs run one at a time in the order added. See waiting runs in Activity, remove queued runs, or stop the active run. Failures do not block later runs. Each run takes a fresh output snapshot, preserving the existing explicit import review and routing flow. Existing command templates using either {url} or {amazonUrl} continue to work.
- Remove the five-minute automatic rescan loop. New profiles default to manual scanning. The existing scan-at-startup preference is preserved; folder watching is a separate opt-in setting, coalesced and limited to at most one automatic scan every 15 minutes. Adding folders and completing imports still refresh the index.
- Open YouTube search in one click from record cards, details, or listening view, without opening the embedded player first. In-app YouTube playback remains available.
- Increase text sizes throughout the app, shorten repeated explanations, and tuck optional usage guidance and empty AI activity behind expandable controls.

This release also includes the AI retry, token usage, and persistent activity features prepared in 0.7.0.

Existing library data, credentials, and preferences are preserved. Version 0.4.1 and newer can receive this update in the app after publication; older installations need one manual installer upgrade. This installer is unsigned.
