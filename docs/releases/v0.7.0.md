AI requests now recover from temporary provider failures, and Activity shows what each AI call did and how many tokens it used.

- Automatically retry network failures, timeouts, rate limits, and temporary server errors, with up to three attempts, exponential backoff, jitter, and bounded Retry-After handling. Invalid keys, access errors, and missing models fail immediately. Cancellation stops pending retries.
- Track discovery, recommendation explanations, collection summaries, and connection checks in Activity, with purpose, result summary, provider/model, status, duration, attempts, and sanitized retry/error details.
- Show provider-reported input, output, total, reasoning, and cached-input tokens for each generation and running totals across restarts. Reasoning and cached input are subsets, so they are not counted twice. Missing usage is explicitly unavailable; totals cover reported usage on this device since tracking began, not a billing estimate.
- Keep the latest 200 completed calls and lifetime totals. Cached discoveries make no new API call. Open Activity during discovery to follow progress, then return to the results.

Existing library data, credentials, and preferences are preserved. Version 0.4.1 and newer can receive this update in the app after publication; older installations need one manual installer upgrade. This installer is unsigned.
