Crate Digger 0.10.0 improves collection browsing and brings favorite tracks in from other music players.

- Fix filter menus opening behind the sidebar. Toolbar popups stay within the window and reposition when it resizes.
- Expand album tracklists directly between collection grid rows. The panel uses a dark color sampled from the album artwork, keeps text readable, and includes track hearts, playback, shuffle, queue, and Play liked actions.
- Import liked tracks from MusicBee or foobar2000 through exported UTF-8 M3U/M3U8 playlists. Review matched and unresolved paths before applying likes. Remember an export and manually refresh it later. Imports add likes while preserving existing likes, ratings, notes, and playlists; music and export files remain unchanged.
- Add artist and year filters alongside genre, rating, and listening filters. Use the toolbar heart to play only liked tracks across the collection, within a filtered scope, artist, folder, or playlist. Play and Shuffle include all matches across pages.
- Remove Explore sample from Settings. Profiles left in sample mode by earlier versions automatically recover their indexed library on restart; onboarding sample mode also has an explicit exit.

See [the liked-track import guide](https://github.com/pasteq7/crate-digger-releases/blob/v0.10.0/docs/LIKED_TRACKS.md) for MusicBee/foobar2000 export and refresh instructions. This is playlist-based import with manual refresh, not live two-way synchronization.

Existing music, library data, credentials, settings, app identity, and update feed are preserved. The installer remains unsigned.
