Fixes stray escape characters in Activity output from external programs.

- Removes terminal color, cursor, title, and hyperlink formatting codes while preserving readable messages.
- Handles formatting codes split across output chunks, with separate handling for standard output and error output.

Existing library data, credentials, and preferences are preserved. Version 0.4.1 and newer can receive this update in the app after publication; older installations need one manual installer upgrade. This installer is unsigned.
