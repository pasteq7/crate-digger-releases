Crate Digger 0.11.0 reduces friction between collection browsing and playback.

- Expand artist and folder tracklists inline, just like albums. Folder view now begins with indexed root folders and shows their paths. Large expansions remain paged instead of loading every row into the interface.
- Follow the current track across collection and track pages, automatically opening its album, artist, or root folder and scrolling it into view. The toolbar toggle pauses following; clicking the player's artwork reveals the track and clears conflicting browsing scopes.
- Preserve shuffle when manually choosing a track or group. Explicit Shuffle actions still enable it.
- Add a persistent Font size setting under General, with larger text and matching player/drawer space.
- Open Track metadata from inline rows, track menus, or the player. Edit title, artist, album/album artist, genre, year, track/disc number, rating, tags, and notes, and inspect source/audio properties. Changes are stored in the library and reflected in playback; original file tags remain read-only.
- Add native APE playback using the bundled Monkey's Audio 13.47 decoder. Decode into a bounded private WAV cache, support seeking, reuse cached audio, and cancel background preparation when abandoned. The decoded limit is 2 GB per file. No external codec installation or Python is required for playback.

See [player and collection controls](https://github.com/pasteq7/crate-digger-releases/blob/v0.11.0/docs/PLAYER_LIBRARY.md) for details. Monkey's Audio is redistributed under its 3-Clause BSD license; the decoder license and source information are included.

Existing music, database, credentials, settings, app identity, and update feed are preserved. The installer remains unsigned.
