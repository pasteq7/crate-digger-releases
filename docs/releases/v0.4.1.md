Adds automatic updates for the installed Windows app through GitHub Releases.

- Checks after launch and every six hours, with background downloads.
- Adds App updates to Settings, download progress, and Restart to update.
- Protects imports, library scans, and external commands from update restarts.
- Preserves library data and preferences; fixes Settings layout in narrow windows.

Install 0.4.1 once to enable future updates if upgrading from an older version. Downloads are automatic; installation waits for your restart action. This installer is unsigned.
