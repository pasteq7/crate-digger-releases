Cleaner Settings and an easier path from external programs to your music library.

- Groups Settings into Library, Appearance & discovery, AI, External program, and App & updates.
- Adds individual activity removal and Clear finished for completed, failed, and stopped terminals. Active programs and imports stay visible; music files are preserved.
- Adds Send to Import music on successful external runs, with newly created folders, ZIPs, and loose tracks already selected.
- Adds Open Import music when the program finishes to open that review step automatically.
- Keeps destination and tagging choices on the Import music page. Choose Import program output to start tagging and moving; drag and drop is no longer required for detected output.

Output detection covers new files under the program's working folder. Existing and modified existing files are excluded, and stopped or failed programs do not trigger the handoff.

Existing library data, credentials, and preferences are preserved. Version 0.4.1 and newer can receive this update in the app; older installations need one manual installer upgrade. This installer is unsigned.
