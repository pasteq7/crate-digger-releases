Quiet Collection turns Crate Digger into a local music library and full-track player while keeping discovery close at hand.

- Reserve the browsing canvas for music. Global search lives in the window bar; view, filter, sort, and page controls live in a compact fixed toolbar. Navigate between Library, Discover, Wishlist, and playlists, with Import music and Settings as utilities.
- Browse owned music by albums, artists, tracks, or folders. Album editions remain separate by their local collection context. Read duration, disc/track ordering, audio properties, folder artwork, and embedded artwork without changing the music files.
- Play local tracks with an independent queue, play-next/enqueue, queue reordering/removal, shuffle, repeat modes, seeking, volume, Windows media controls, and a compact mini-player mode. Restore the queue and position paused on startup. Discovery previews pause the local session and offer Return to your music.
- Add manual or rule-based smart playlists, favorites, ratings, personal tags/notes, and library-only metadata corrections. Import/export M3U playlists, review duplicate candidates, back up library details, and review a moved-folder mapping before recovering playlist identities. These tools do not retag, move, rename, or delete existing audio.
- Choose Sage, Ink, Plum, Ember, Paper, or Mono, or create/import/export custom palettes with contrast validation and live preview. Support separate light/dark system palettes, collection density, and startup destination preferences.
- Organize Settings into General, Library, Playback, Discovery, Connections, and About & updates. Save connections explicitly and protect unsaved connection edits when navigating away. Move AI accounting into connection usage/history and background progress into Tasks.
- Launch configured external tools from Import music → From a music link or a record action. Inspect task logs on demand, then review output in Import music before starting a verified import. Existing command templates and import semantics are preserved.
- Add optional ReplayGain normalization using existing tags, optional crossfade for consecutive local tracks, and separate local listening history with a clear-history control.

Playback was checked with generated MP3, FLAC, M4A/AAC, Ogg, Opus, and WAV files. AIFF, WMA, APE, and WavPack may be indexed but are not supported by the current playback backend. Unsupported/missing files report an error and can be skipped. This release does not claim sample-accurate gapless or exclusive/bit-perfect output.

The existing database, credentials, preferences, shelves, app identity, and update feed are preserved. Existing music stays read-only outside explicitly requested imports. Installations older than 0.4.1 still require one manual installer upgrade to enable updates. The installer is unsigned.
